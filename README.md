# Lesotho Tourism Website

A responsive, six-page tourism website created as a student project for Web Design (BIWD2110).

## Pages
- `index.html` — Home
- `destinations.html` — Searchable and filterable destinations
- `accommodation.html` — Accommodation information and sample prices
- `activities.html` — Activities and travel information
- `gallery.html` — Photo gallery with a lightbox
- `contact.html` — Contact form and sample booking cost calculator

## Run locally
1. Extract this folder.
2. Open `index.html` in a web browser.
3. Keep the `css`, `js`, and `images` folders alongside the HTML files.

Bootstrap 5.3.3 is loaded from jsDelivr, so an internet connection is needed for Bootstrap styling and components. The site's own CSS, JavaScript, and images are stored locally.

## Publish with GitHub Pages
Upload the contents of this folder to the root of your GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Notes
The accommodation prices are sample prices for coursework. The contact and booking forms demonstrate front-end validation and a booking estimate; they do not transmit messages or reservations to a real business.
